# deadtildawn

2D mobile touge racing RPG (portrait, iPhone target). Story: six years ago the player was a legend of the SoCal canyon scene in a self-built 2009 Civic Si (FA5). In a $50k race against the Nissan club's top dog (his 370Z, the final boss), one corner too hot at 87 mph: the car hit a tree and burned, and the player survived but lost strength and feel in the right leg and left the scene. Best friend **Faba** got them back on their feet. Six years later Faba quits his corporate job, buys a stock '96 Civic DX coupe 5MT, and spends his savings on a warehouse (home + HQ): "You build it. I drive it." The player never drives: races are physics simulations shown as a broadcast-style replay with live telemetry. (The story's words live in `godot/voice.gd` STORY_*: a VHS tape of the old days and the crash, then Faba's text thread; `intro.gd` plays them.)

The physics simulator is also Spire's Physics 3 showcase project at Oxnard College (due ~early December 2026): "Can first-year physics predict a real car's performance?"

## Architecture

Godot calls `tools/game_bridge.py` (Python) in a background thread (`bridge.gd`) and reads one JSON reply per command (versioned contract, tested in `tests/test_bridge.py`). Replays use the `deadtildawn-replay` format (`tools/export_replay.py`; optional fields like `ghost`, `dnf` keep old viewers working).
- **Hub shell (garage workbench, `docs/ART_DIRECTION.md` is the art bible):** `screens/shell.tscn` is the persistent hub frame: pegboard wall + shop light, taped avatar/name, a receipt for cash/rep, a Dymo label for the location, and a tool-chest bottom nav (drawers with masking-tape labels: `$$$` / car / home / cal / team; open drawer = `DrawerOpenButton`). `game.gd` creates it once and swaps only its content (`open_hub(scene, tab)`), so the nav never rebuilds. ## Conventions

- SI units inside the sim; convert only for display (`sim/units.py`).
- Car JSON stores inputs only. `Car` is a frozen dataclass; variants via `dataclasses.replace` (parts, opponents) — the stock car is never modified.
- One job per function; physics functions get hand-calc unit tests. The physics spec (`docs/physics writeups/physics main.md` + `docs/PHYSICS_updates_*.md`) gets an update file with physics changes. Log every model change in `docs/VALIDATION_LOG.md`.
- Validation targets come from measured data, never our own predictions. No knob-turning to match data.
- Fixed-point iteration for circular models (brake temperature over a lap, load transfer vs grip, traction).
- Results must be step-size converged. Game comparisons always use `GAME_DS`.
- Data files fail loudly on typos (unknown effects/slots raise).
- GDScript gotcha: a lambda's body ends at a newline; wrap a multi-line expression in parentheses (`func(r): return (a\n and b)`), hit 3x.
- GDScript gotcha (hit 5x): `:=` can't infer a type from untyped Array elements or generic `InputEvent` fields. Type explicitly (`var x: float = ...`, `for side: float in [...]`).
- Godot layout gotchas: a PanelContainer stretches every child over each other (put ONE container inside); a wrapping Label inside an HBoxContainer, or with a SHRINK size flag anywhere, collapses to one character per line (`UI.label` wraps by default in columns: turn it off for stamps/tags).

## Physics model (detail in the physics spec, see docs/)

- QSS point mass, distance-based integration with event detection (fuel cut, shift end)
- Track: flat; pace notes like `S 200, R7 65, L1 180`; severity 1-10 = radius 15-500 m (geometric); strict parser; crossing detection
- Longitudinal: digitized torque curve, gearing, launch with clutch slip, 0.4 s shifts, rotational inertia (effective mass), drag, rolling resistance, **FWD or RWD traction** (`traction_limit`; load transfer + load-sensitive tires, fixed point). RWD check: 50/50 car, constant mu 0.9 hand calc 5926 N; sim with load sensitivity 5815 N.
- Shifting: sequential only; no money shifts; no mid-corner shifts
- Cornering: lateral load transfer (roll stiffness split), per-tire load sensitivity, axle-limited (stock DX understeers at 0.832 g)
- Braking: forward load transfer + load sensitivity; capacity ratio 1.3; rotor thermal model, pad fade above 350 C
- Driver: **human timing** (PHYSICS_updates_F 6.z): launch reaction N(0.20, 0.07) s and each shift's duration x N(1, 0.175), own random stream; run spread ~0.11 s. Push level f (safe 0.947 / normal 0.954 / hard 0.972 / flat out 0.986) x driver `skill`; attempt ~ N(f, sigma) per corner; attempt > 1 = mistake (runs wide); **attempt > 1.025 = CRASH (DNF)**: the run ends at that corner's apex (`lap.dnf`, `lap.crash_corner`; compare runs with `finish_time()`, inf for DNF). Crash chance per 5-corner run: 0.02% / 0.09% / 2.1% / 12.2%. Corner technique: carry speed in, ease to the apex, roll on to the exit (rpm never steady); gentle slowing = feathered throttle, not brakes.
- Not yet: friction circle, elevation, aero/downforce, suspension dynamics, racing line (car follows the centerline)

## Game design (current)

**Loop:** warehouse (hub) -> parts (pulls, counter, spares) -> calendar -> race night -> broadcast replay -> results (cash, rep, damage).

**Race night order (Spire, Oct 2026; `game.gd show_briefing()`):** 1. THE ROAD (`screens/scout.tscn`, a hub screen: the map with corner colors + the key `widgets/severity_key.gd`, the road read (bridge `road_read`, `sim/roadread.py`: straight share, full throttle / braking share for THIS build, longest straight, tightest corner, hairpins; numbers only, no "power road" verdict: Spire, the player reads them), the DX as it sits; bridge `road` = road only, no opponent) -> 2. build for it in CAR ("back to tonight's road") -> 3. LOCK IT IN (`lock_build()`: `night["parts"]` saved; `build_locked()` refuses installs, counter buys go on after the night) -> 4. the opponent is matched to the locked build (street: matched + tuned to 50%; rival: as he is) -> 5. the meeting (stat card, push, bet) -> SEND IT. Each step is saved. Corner names are gone from the meeting maps and the replay (colors only; the results map keeps them: its swings name corners).

**Inspiration:** Hothead's Big Win series (build a team, open packs, watch a simulated race). NO real-money purchases; the physics, not stat bars, decides races. Dropped: call cards.

**Driver meeting (decided):** NO percentages and no practice chart (Spire: the chart was "win % made visual", too easy). The player sees a **stat card**: the DX vs the opponent's car (power, torque, weight, power/weight, drivetrain, 0-60, skidpad), the opponent's engine condition (tired/worn/healthy/fresh), and a one-line driver read ("Sharp, drives a steady pace..."). Push levels are described in words with what you're risking (`PUSH_TALK`). Every choice must carry severe consequences: easy to lose, easy to wipe progress.

**Spire's friends (street racers, `data/opponents.json`, authored `read` = the stat card's driver line, `sim/opponents.py driver_read`):** Jorge, 1995 Honda Accord LX (F22B2, ~1340 kg; "Scrolling on reels half the time.": loose, sigma 0.034), Brandon, 2007 Honda Civic DX (base 8th gen R18, ~1200 kg; "Has an issue with fire hydrants and reversing.": pushes hard, sigma 0.033). Both close to the DX's power-to-weight, so they show up early. Calibrated: the heavy Accord needs condition 1.24 (a "fresh" 165 hp) to be a coin flip vs a stock DX. Looks: car_sprite / car_model `2007 Honda Civic` (before `Civic`, Faba's) and `Accord`.

**Opponents (decided):** simulated head-to-head. Each opponent = base car + changes (`data/opponents.json`: same effects as parts, plus drivetrain and weight split) + an authored driver (push, sigma, skill; Oct 2026: sigma +0.008, skill near 1, so they make mistakes and crash). Difficulty = engine `condition` (scales output; the stat card shows the true hp). **Street racers are matched and tuned EVERY NIGHT to ~50% at the player's best push** (Spire: a well-played night is a coin flip). Rivals start at their calibrated condition (Zed: 45% vs a stock DX) and re-tune against the current build only after the player beats them (`state["rivals"]`), never softer: building between rival nights is how you climb. The night's condition is saved with it and passed to the race (`--opp-condition`).

**The cops (Spire, Oct 2026):** a race that FINISHES (win or loss, not a crash) has `COPS_CHANCE` 3% to get pulled over (`apply_result`): speeding + reckless driving, a fine of `COPS_FINE_MINS` 3 x tonight's minimum bet (never below $0), and NO winnings on a win (a loss still costs the wager); `result["cops"]` = {fine, seized}, `stats["tickets"]`. Results shows a citation (`%Ticket`, FlyerYellowPanel; words `Voice.COPS_*`, DRAFTS), Faba says `FABA_COPS`, a siren; the replay's chase gets red/blue lights behind the camera car at the end (`busted`). Game test checks the fine and the $0 floor.

**How to race (Spire: "jorge says it's too difficult"):** `screens/tutorial.tscn` (a hub screen, pages from `Voice.TUTORIAL` [title, body, Faba's line], DRAFTS): opens by itself the first race night (`state["tutorial_seen"]`), and from "how to race?" on the road screen and the meeting. Its push page is REAL numbers: a stock DX at each push, 300 races vs street racers matched to 50%, three road styles: safe ~43%, normal 48-51% (0 crashes), hard 42-52% (~1% crash), flat out 20-36% (14-20% crash). NORMAL is the best default; flat out is a trap (a design question: should it ever pay?).

**Consequences (decided):** open-road win +4 rep, rival win +15 (Spire wants a rep revamp later); any loss -5 rep; crash (DNF) -20 rep, wager lost, $150 body/tow, and EVERY installed part rolls: 10% destroyed, 40% damaged (off the car until repaired; repair = 30% of price). Both crash = no contest (wager returned, damage still applies). Rep floor 0. Under tonight's minimum bet -> BROKE (`screens/broke.tscn`): scrap any part, even off the car (price x 0.25 x (0.5 + q)), to get back over it, or START OVER. Skip a race night: -50 rep, impossible below 50 rep.

**Part pictures (Spire: "more visual"):** `widgets/part_art.gd` draws every catalog part in code (a 90s parts-catalog sticker: flat colors, ink outline; 4-1 vs 4-2-1 headers, street vs race cams, three tire compounds, light vs forged wheels...; an unknown id = a box). Theme variation `PartArt` (colors + font). Shown big on the reveal (`%PartPic`, the rarity glowing behind it), on the swap card (`%ComparePic`), small on the build sheet (per slot) and on every bench / counter / shelf row in $$$. CAR has "take it all off" (`strip_car` / `strip_all`: every part back to the spares, no swap card; refused while locked in).

**Parts + gacha:** catalog `data/parts/catalog.json` (24 parts, 14 slots: intake, header, cams, ECU, flywheel, shifter, final drive, tires, wheels, rear sway bar, springs, interior, hood, seats). `sim/parts.py apply_parts` returns a modified copy. Every owned part is a rolled INSTANCE (`sim/gacha.py`): hidden quality q in [0,1]; benefits scale up and drawbacks down with q; q = 0.5 = catalog numbers; fixed-spec parts (final drive, sway bars) don't roll. Pulls (`data/parts/pulls.json`; Spire, Oct 2026): junkyard $150 (rep 0), used marketplace $500 (rep 50; id `swap_meet`), sealed crate $1250 (rep 125), import $3000 (rep 300) with rarity weights, quality ranges, and pity (guaranteed rarity within N pulls). New pulls are unopened until the free **dyno reveal**. The counter sells commons new (q 0.5). Spares sell for scrap (price x 0.25 x (0.5 + q)). Loot: 5% per win via the hidden "loot" source. Flyer lines (blurb + Sharpie note) are in `voice.gd` PULL_BLURBS / FLYERS. Counter (common) prices raised Oct 2026, the interior strip most (-40 kg, $1400). The game never lets you spend below the $100 buy-in. Exact specs shown, never lap times. Bridge passes parts as `--parts id@quality,...`.

**Calendar:** week + day. Friday + Saturday every week: open roads (two different generated roads a week, `open_road(n)`, style rotates technical/balanced/flowing) vs a matched street racer. Every 2nd Sunday: the rival on his home road. 4 open : 1 rival.

**Procedural tracks:** `sim/trackgen.generate(seed, style)` -> pace notes; rejects crossings and near misses (min clearance 22 m); never two straights in a row. Lesson: "technical" requires packed corners.

**Economy:** start $200. Minimum bet `min_bet()` = $100 until the first rival night is behind you, +$100 per rival night (raced or skipped); max bet = 5x the minimum; it's also the BROKE line and the floor no purchase can cross. Even money vs single racers. Above $2000 the bet is drawn as banded stacks (`cash_stack.gd`). Boss battles (later): the lower-rep underdog puts up more.

**Rival club (Nissan ladder, later):** 280Z (Zed, rung 1, tired 124 hp L28) -> Sentra SE-R -> 240SX -> R33 GT-R -> R35 GT-R -> 370Z (final boss, inspired by Spire's best friend's car). Race each rival several times; rivals upgrade in proportion to the player, then the player moves up.
